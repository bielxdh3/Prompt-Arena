# Prompt Arena v0.1.4 Beta

This is the first consolidated GitHub beta release from the clean replacement stack merged through PR #58.

## Highlights

- Local-first Tauri 2 desktop app for Windows and Linux.
- Core Arena evidence, blind evaluation, immutable run history and export paths.
- Ollama, LM Studio and llama.cpp/GGUF model-library boundaries.
- Single-model benchmark, Performance Lab evidence, historical regression, deterministic Elo v1 ratings, Robustness Arena and Repro Bundle feature slices.
- Optional BYOK provider architecture with explicit credential/network/cost boundaries.
- Human-readable labels instead of raw internal IDs.
- PT-BR/English UI improvements and localized failure presentation.
- Windows production GUI subsystem with no intentional console window.
- Responsive/theme/motion/accessibility QA, including the repaired two-ring PA atom animation.
- Windows MSI/NSIS and Linux DEB/AppImage release pipelines.

## Beta warning

v0.1.4 is **not a claim of production completeness**.

Known open areas include:
- reasoning-model generation may consume its output budget before producing user-visible text under the current provider contract;
- TTFT, system/GPU telemetry and energy measurements are not yet complete;
- llama.cpp live acceptance and Docker-required benchmark smoke remain open;
- historical/statistical workflows are useful but not yet at their intended final depth;
- imported Repro Bundles verify integrity/differences but do not yet reconstruct and launch a full rerun automatically;
- release signing is not guaranteed. Check the release assets and notes before assuming a binary is signed.

## Integrity

Release assets are built by GitHub Actions from the exact release ref. The release includes checksum and package-verification evidence generated by the packaging workflow.
