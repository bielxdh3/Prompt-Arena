# Code of Conduct

Prompt Arena expects technical discussion to stay professional, specific and respectful.

## Expected behavior

- Critique code, evidence and decisions rather than people.
- Be clear about uncertainty and distinguish fact from opinion.
- Give contributors enough context to reproduce problems.
- Respect privacy, credentials, unpublished benchmark data and security boundaries.
- Accept maintainer decisions on scope while remaining free to disagree constructively.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, doxxing, deliberate exposure of secrets, spam, sustained personal attacks, or knowingly misleading technical claims are not acceptable in project spaces.

## Enforcement

Repository maintainers may edit, hide or remove abusive content; lock discussions; reject contributions; or restrict participation when necessary to protect contributors and the project.

For conduct concerns that should not be public, contact the repository owner privately through GitHub.
