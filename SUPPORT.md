# Support

Prompt Arena is currently a beta project without a commercial support SLA.

## Bugs

Use the GitHub bug-report form with reproduction steps, Prompt Arena version, operating system, runtime, and relevant logs with secrets removed.

## Feature requests

Use the feature-request form and explain the user problem, not only a proposed implementation.

## Security

Do not report vulnerabilities or credentials in a public issue. Follow `docs/SECURITY.md` and use GitHub private vulnerability reporting when available.

## Runtime-specific problems

When reporting Ollama, LM Studio or llama.cpp behavior, include the runtime version, model identity, quantization/profile settings, and whether the problem reproduces outside Prompt Arena. Never attach API keys or unrelated private model data.
